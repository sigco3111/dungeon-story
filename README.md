# Dungeon & Story

### 황량한 땅을 개척하여 번성하는 마을을 건설하고, 던전 깊은 곳의 위협에 맞서 싸우는 마을 성장 RPG!

*Dungeon & Story*는 자원 관리와 RPG 요소가 결합된 게임입니다. 플레이어는 던전을 탐험하여 몬스터를 처치하고 귀중한 자원을 수집해야 합니다. 이 자원들을 사용하여 아무것도 없던 마을에 건물을 짓고 업그레이드하며, 점차 강력해지는 위협으로부터 마을을 지켜내야 합니다. 당신의 성장이 곧 마을의 번영이며, 마을의 발전이 곧 당신의 새로운 힘이 됩니다.

실행주소1 : https://dungeon-story.vercel.app/

실행주소2 : https://dev-canvas-pi.vercel.app/

## 🎮 주요 특징 (Key Features)

- **마을 건설 및 성장:** 대장간, 연금술사의 집, 여관 등 다양한 기능적 건물을 건설하고 업그레이드하세요. 건물의 레벨이 오를수록 새로운 제작법이 해금되거나 특별한 기능이 강화됩니다.
- **깊이 있는 제작 시스템:** 던전에서 얻은 재료로 무기, 방어구, 물약을 제작하세요. 제작된 아이템은 '일반', '고급', '희귀' 등급을 가지며, 높은 등급일수록 강력한 성능을 발휘합니다.
- **장비 강화:** 대장간에서 장비를 강화하여 한계를 돌파하세요. 강화 실패 시 단계가 하락할 수 있는 위험을 감수하고 최고의 장비를 만들어내야 합니다.
- **자동 전투 시스템:** 전투는 자동으로 진행됩니다. 플레이어의 역할은 탐험 전 철저한 준비(장비, 물약, 버프)를 통해 전략을 세우는 것입니다.
- **다양한 던전과 무작위성:** 각기 다른 자원과 몬스터가 등장하는 던전을 탐험하세요. 던전에 입장할 때마다 "몬스터 체력 증가"와 같은 무작위 속성(어픽스)이 부여되어 매번 새로운 도전을 제공합니다.
- **NPC, 평판, 퀘스트:** 마을 주민들과 교류하고 퀘스트를 완료하여 보상을 받고 평판을 쌓으세요. 높은 평판은 특별한 아이템 제작법이나 숨겨진 퀘스트를 해금하는 열쇠가 됩니다.
- **마을 방어전:** 주기적으로 몬스터들이 마을을 습격합니다. 성벽과 경비탑을 업그레이드하여 소중한 건물들을 지켜내세요.
- **엔드게임 콘텐츠:**
  - **무한의 균열:** 자신의 한계를 시험하는 끝없는 던전에서 최고 기록에 도전하세요.
  - **월드 보스:** 특정 조건 하에 등장하는 강력한 보스를 처치하고 희귀한 보상을 획득하세요.
  - **도전 과제:** 다양한 목표를 달성하고 영구적인 보상을 받아 캐릭터를 더욱 성장시키세요.

## ♻️ 핵심 플레이 흐름 (Core Gameplay Loop)

게임은 다음과 같은 순환 구조를 통해 진행됩니다.

1.  **탐험 (Explore):** 던전에 입장하여 몬스터를 처치하고 `골드`, `목재`, `석재`, `철광석` 등 마을 건설과 장비 제작에 필요한 자원을 획득합니다.
2.  **건설 (Build):** 마을로 돌아와 수집한 자원으로 `대장간`, `훈련소` 등 새로운 건물을 짓거나 기존 건물을 업그레이드하여 마을의 기능을 확장합니다.
3.  **제작 (Craft):** 새로 지은 건물이나 업그레이드된 건물의 기능을 활용하여 더 강력한 무기, 방어구, 물약을 제작합니다.
4.  **성장 (Grow):** 더 좋은 장비를 갖추고 강력해진 플레이어는 이전에는 어려웠던 상위 던전에 도전할 수 있게 되며, 이는 더 좋은 자원 획득으로 이어집니다.

## 🚀 시작하기 (Getting Started)

1.  **첫 번째 목표:** 게임의 첫 목표는 `초심자의 숲`에서 `목재`와 `석재`를 모으는 것입니다.
2.  **대장간 건설:** 자원이 모이면 첫 번째 기능 건물인 `대장간`을 건설하세요. 이것이 마을 발전의 첫걸음입니다.
3.  **장비 제작:** 대장간에서 `낡은 검`과 `가죽 갑옷`을 제작하여 캐릭터의 기본 전투 능력을 향상시키세요.
4.  **퀘스트 확인:** 마을의 `장로`가 주는 퀘스트를 확인하고 완료하여 게임의 흐름을 따라가세요. 퀘스트는 풍부한 보상과 함께 다음 목표를 제시해 줍니다.

## 🛠️ 기술 스택 (Tech Stack)

이 게임은 다음과 같은 기술을 사용하여 제작되었습니다:

-   **Frontend:** React, TypeScript
-   **Styling:** Tailwind CSS
-   **State Management:** React Hooks (`useState`, `useEffect`, `useCallback`)
-   **Data Persistence:** Browser `localStorage` API
